\section{Self-Hosted \acrshort{LLM}}\label{sec:self_hosted_llm}
During the~\ref{subsubsec:risk_evaluation} we realized that the costs for \acrshort{AI} tokens required to use cloud based \acrshort{LLM}s might cause huge costs.
\todo{Add source for the cost claim}
As the project team already has existing hardware which is suitable for running smaller \acrshort{LLM}s, one of the possibilities to avoid this risk is the usage of self-hosted \acrshort{LLM}s.
Besides eliminating the costs for \acrshort{AI} tokens, at least during the development phase, it also allows the quick evaluation of different \acrshort{AI} Models.
Depending on the quality and performance of the smaller models running in the self-hosted setup we can consider not using a cloud based \acrshort{LLM} at all.
