\textit{19.02.2026 -- 10.03.2026}

This is the initial milestone which is used to plan the whole project and bachelor thesis.

\begin{itemize}
    \item[$\checkmark$] The bachelor thesis is planned as an agile (scrum-like) project
    \item[$\checkmark$] A risk analysis for the project was conducted and the identified risks are assessed and addressed
    \item[$\checkmark$] All meetings, deadlines, scrum ceremonies and sprints are added to the Outlook calendar
    \item[$\checkmark$] The goals of the thesis are defined and categorized as \enquote{must}, \enquote{should} and \enquote{could}
    \item[$\checkmark$] The goals are created as milestones and divided into epics, categorized by the labels: Project Management, Research, Framework, Implementations, Documentation
    \item[$\checkmark$] We know how we coordinate the project with the stakeholders (instructor and expert)
\end{itemize}
