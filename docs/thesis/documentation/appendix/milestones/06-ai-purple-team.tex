\subsubsection{\href{https://gitlab.ti.bfh.ch/groups/gausf1-vonal3/-/milestones/18}{NSAK Scenario: AI -- Purple Team}}\label{subsubsec:milestone-ai-purple-team}
\textit{19.03.2026 -- 16.04.2026}

This milestone explored what happens when an \glsxtrshort{AI} agent is given full access to the \glsxtrshort{NSAK} framework for both Red and Blue Team activities.
The scenario is intentionally open-ended, reflecting the research nature of the milestone.

\textbf{Goals (Must):}
\begin{itemize}
    \item[$\square$] The operator can provide a custom prompt or select a predefined Red or Blue Team prompt
    \item[$\square$] The scenario runs an \glsxtrshort{AI} agent with a remote connection
    \item[$\square$] An operator can interact with the agent via \glsxtrshort{CLI} at all times
    \item[$\square$] The scenario logs all relevant actions and network traffic locally
    \item[$\square$] The \glsxtrshort{AI} can trigger an e-mail alert to notify an operator
    \item[$\square$] The scenario has a kill switch to stop execution at any time
\end{itemize}

\textbf{Goals (Should):}
\begin{itemize}
    \item[$\square$] Human interaction hook via Web \glsxtrshort{GUI}
    \item[$\square$] Remote logging and sniffing
    \item[$\square$] Kill switch with full device shutoff
\end{itemize}
