\subsubsection{\href{https://gitlab.ti.bfh.ch/groups/gausf1-vonal3/-/milestones/20}{Reproducible Test Environment}}\label{subsubsec:milestone-test-environment}
\textit{19.03.2026 -- 02.04.2026}

The goal of this milestone was to design and implement a reproducible and safe test environment for the \glsxtrshort{NSAK} framework, providing a stable basis for consistent execution and evaluation of both manual and \glsxtrshort{AI}-assisted scenarios.

\begin{itemize}
    \item[$\checkmark$] The test environment can be set up reproducibly using Infrastructure as Code (e.g.\ Ansible).
    \item[$\checkmark$] \glsxtrshort{NSAK} scenarios and drills can be executed consistently within the environment.
    \item[$\checkmark$] The environment supports both manual and \glsxtrshort{AI}-assisted scenarios.
    \item[$\checkmark$] Scenario results can be collected and analyzed for evaluation purposes.
\end{itemize}
