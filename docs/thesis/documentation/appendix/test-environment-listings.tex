\subsection{Flaws and Vulnerabilities}\label{subsec:flaws-and-vulnerabilities}


\begin{listing}[H]
	\caption{Introduced Vulnerabilities in the Virtual Enterprise Network}
	\label{lst:flaws-and-vulnerabilities}
	\begin{minted}[
		fontsize=\scriptsize,
		breaklines,
		breakanywhere,
		linenos,
		tabsize=2
		]{text}
		DMZ --- dmz-server (172.16.1.10)

		DNS / BIND9
		- allow-transfer { any; } --- AXFR (zone transfer) open to everyone
		- dnssec-validation no --- no DNSSEC validation
		- Zone contains internal LAN addresses (ctrl, alice, bob, printer)

		Web / nginx
		- /secret.txt accessible without auth -> returns DB Password: {flag:exposed-SOS}
		- Self-signed certificate (CN=dmz-server.vlab.local)
		---
		LAN --- ctrl-server (192.168.10.5)

		LDAP / OpenLDAP
		- by anonymous read --- anonymous read access to all entries -> user list, emails, departments
		- rootpw Password123! stored in plaintext in config
		- User passwords stored in LDIF: userPassword: Password123!
		ldapsearch -x -H ldap://192.168.10.5 -b "dc=lab,dc=local"

		SMB / Samba
		- ntlm auth = yes + lanman auth = yes --- outdated, weak auth protocols
		- Share public anonymously readable (no auth) -> README.txt hints at bjones
		- Share finance contains salary and budget data (asmith / Password123!)
		- Share it contains dc01_build_sheet.txt with full infrastructure details
		- All passwords: Password123!
		---
		LAN --- alice (192.168.10.100) \& bob (192.168.10.101)

		- SSH password auth enabled, weak password Password123!
		- SSH banner leaks organisation name
		- alice: /home/asmith/Documents/Q3_Finance.txt (confidential), /home/asmith/Desktop/drive_mappings.txt (share paths)
		- bob: /home/bjones/Scripts/hosts.txt (all internal IPs + roles), README.txt hints at admin access
		---
		LAN --- printer (192.168.10.50)

		- Port 80: unauthenticated web admin interface, leaks firmware version (HP-WebServer/2.6.5), serial number, location, contact
		- Port 631 /jobs: print job history without auth -> reveals usernames (asmith, bjones, admin) and document names
		(server_credentials.txt, payroll)
		- SNMP community string public (v1/v2c) -> snmpwalk exposes full device info
		---
		Firewall policy (intentional gaps)

		- LAN -> DMZ fully open (no port restriction) --- LAN users can reach all DMZ ports, not just 80/443
		- DMZ -> WAN: DNS forwarding to 8.8.8.8 allowed -> DNS exfiltration possible
	\end{minted}
\end{listing}
