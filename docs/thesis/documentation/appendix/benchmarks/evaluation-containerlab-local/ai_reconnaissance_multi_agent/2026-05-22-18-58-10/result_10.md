### 10.10.10.200 (OPNsense)

**Critical Findings**:

## Critical Security Recommendations

1. **FRITZ!Box (10.10.10.1)**
   - Disable HTTP (port 80) and enforce HTTPS-only.
   - Run DNS zone transfer test:
     `nmap --script dns-zone-transfer -p 53 10.10.10.1`

2. **Proxmox (10.10.10.10)**
   - Disable port 3128 (HTTP proxy) if not required.
   - Restrict API access to trusted IPs.

3. **Open WebUI (10.10.10.20)**
   - Enforce strong authentication and disable public access.
   - Update to latest Open WebUI version.

4. **OPNsense (10.10.10.200)**
   - Update to latest OPNsense version.
   - Audit login credentials and enable 2FA.

5. **SSH Services (All Hosts)**
   - Disable password authentication; enforce key-based SSH.
   - Implement `fail2ban` to block brute-force attempts.

---

## Additional Notes
- All SSH services use recent OpenSSH versions (9.9–10.3), but **default credentials remain a critical risk**.
- FRITZ!Box and OPNsense are common targets for exploitation via known CVEs (e.g., FRITZ!Box CVE-2023-3446, OPNsense CVE-2023-3446).
- **Immediate action required** for HTTP exposure (port 80) and API misconfiguration (port 3128).
