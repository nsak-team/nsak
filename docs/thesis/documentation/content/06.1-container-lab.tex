\section{Virtual Environment (Containerlab)}\label{sec:eval-containerlab}

\paragraph{Overview}

Tables~\ref{tab:overview-containerlab-single} and~\ref{tab:overview-containerlab-multi} present
results for both the single-agent and multi-agent configurations, where the multi-agent setup splits
the reconnaissance scenario into three specialised sub-tasks.
The subsequent quantitative and qualitative analysis focuses on the multi-agent set up, as it
constitutes the primary contribution of this work.
Overall, discovery quality in the Containerlab environment is comparable between the single-agent
and multi-agent configurations, while smaller models benefit noticeably from task decomposition.

Comparing the two configurations, \texttt{claude-opus-4-7} achieves near-identical discovery quality
in both modes (9 services, 8 findings), confirming that the frontier model is robust regardless of
set up.
In contrast, the smaller models profit from decomposition: \texttt{qwen3:30b} improves from 7 to 8
services and reduces duration from 362\,s to 252\,s, while \texttt{gpt-oss:120b} improves from 6 to
7 services and from 4 to 5 findings.
The \emph{Static Scenario} serves as the reference baseline, discovering all 5 hosts, 13 services
via exhaustive port scanning, and 8 findings in a deterministic 29\,s execution.
Overall does all models profit from the decomposed context with a higher success factor.

Figure~\ref{fig:benchmark_duration_containerlab} visualises the mean run duration per model.
\texttt{claude-opus-4-7} completes in 150\,s, \texttt{qwen3:30b} in 252\,s, and
\texttt{gpt-oss:120b} in 847\,s.
The Static Scenario at 29\,s reflects the baseline and reference static scenario with a fixed execution time of the deterministic script.


\begin{figure}[H]
    \centering
    \includesvg[width=0.8\linewidth]{figures/containerlab/benchmark_token_usage_26_05_2026_multi_agent.svg}
    \caption{Mean total token usage per model (Containerlab, multi-agent, $n=10$ runs each).}
    \label{fig:benchmark_tokens_containerlab}
\end{figure}

Figure~\ref{fig:benchmark_tokens_containerlab} shows mean token consumption per model.
\texttt{claude-opus-4-7} uses 59,988 tokens, \texttt{gpt-oss:120b} 46,736, and \texttt{qwen3:30b}
the fewest at 27,789.
Token count alone is not a reliable factor for result quality: \texttt{claude-opus-4-7} achieves
the best outcomes while consuming the largest amount of tokens.


\begin{figure}[H]
    \centering
    \includesvg[width=0.8\linewidth]{figures/containerlab/benchmark_tokens_vs_duration_26_05_2026_multi_agent.svg}
    \caption{Total tokens vs.\ run duration per individual run (Containerlab, multi-agent, $n=10$ per model).}
    \label{fig:benchmark_scatter_containerlab}

Figure~\ref{fig:benchmark_scatter_containerlab} plots total token consumption against run duration
for every individual run.
\texttt{claude-opus-4-7} remains consistently in the low-duration region and also consumes reliable for every run the same amount of tokens.
\texttt{qwen3:30b} clusters in the low-token, mid-duration region, notable that the avg token consumtion and
\texttt{gpt-oss:120b} occupies the far-right, confirming its consistently high duration.
The horizontal dashed line for the Static Scenario reflects its fixed 29\,s execution with no
token consumption.
The spread within each model's cluster reveals run-to-run variability in how deeply the
\acrshort{AI} agents chose to enumerate hosts and services before concluding.


\begin{figure}[H]
    \centering
    \includesvg[width=0.8\linewidth]{figures/containerlab/benchmark_services_26_05_2026_multi_agent.svg}
    \caption{Average hosts, services, and findings discovered per model (Containerlab, multi-agent, $n=10$ runs each).}
    \label{fig:benchmark_services_containerlab}
\end{figure}

Figure~\ref{fig:benchmark_services_containerlab} compares discovery breadth across models.
\texttt{claude-opus-4-7} consistently discovers all 5 reachable hosts, 9 services, and the maximum
of 8 findings, matching the deterministic baseline on findings.
\texttt{qwen3:30b} reaches 8 services and 5 findings; \texttt{gpt-oss:120b} discovers 7 services
and 5 findings.
The Static Scenario's 13 services exceed all \acrshort{AI} models because the script issues
exhaustive port sweeps unconditionally, while \acrshort{AI} agents terminate scanning early once
they judge the network to be sufficiently enumerated.
