% Time form: Present Tense

% Context
As adversaries grow in number, security teams increasingly rely on \textbf{red and blue team exercises} to identify vulnerabilities before they can be exploited.
Manually engineered scenarios offer flexibility and reproducibility, but require a high level of cybersecurity expertise and lack adaptability to changing conditions.
\textbf{Large Language Models}, by contrast, can reason over tool output and dynamically adjust their behavior.

% Research question
This thesis investigates whether \textbf{agentic AI} can effectively automate and enhance network security scenarios within the \textbf{NSAK} framework — a modular Python-based cybersecurity orchestration platform developed in a predecessor project.

% Approach
To address this question, the framework is extended with an agentic drill integration built on \texttt{LangChain}.
The agent is equipped with tools for CLI interaction, host configuration, and autonomous \textbf{purple team reconnaissance}.
A deterministic reference scenario — chaining the drills \texttt{host-discovery}, \texttt{port-scanning}, and \texttt{service-enumeration} — serves as the reproducible baseline.

% Evaluation
Three models are benchmarked across 10 runs in three environments (\emph{containerlab}, \emph{physical lab}, and \emph{BFH Cyber Lab}):
a frontier model (\texttt{Claude Opus 4.7}), an institutionally hosted open-weight model (\texttt{gpt-oss:120b}), and a locally-run open-source model (\texttt{qwen3:30b} via Ollama).
