\chapter{Implementation}\label{ch:implementation}

To address these questions, an \gls{AI} agent based on \gls{LangChain} is integrated into the framework.
The agent is equipped with tools for retrieving the hosts network configuration,
autonomous \gls{CLI} command execution, requesting human input and notification via email.
To simplify the usage of \gls{NSAK} a configuration management is introduced,
which allows users to configure different \glspl{LLM} and manage secrets for external systems such as email and logging.
